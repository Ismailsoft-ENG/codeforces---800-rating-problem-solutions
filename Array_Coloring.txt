Codeforces - Array Coloring
Language: C++

Approach:
1. Read the number of test cases t.
2. For each test case, read n and then all n array elements.
3. Calculate the total sum of the array.
4. If the total sum is even, print YES; otherwise, print NO.

Why does this work?
We need to split the array into two non-empty colors so that both color sums have the same parity.
If both sums have the same parity, their total must be even.
Also, when the total sum is even, an array with at least two elements can be split into two non-empty groups with matching parity:
- If there is an even element, put that element in one group and the remaining elements in the other.
- If all elements are odd, the total being even means there are an even number of odd elements; we can put one odd element in each group and distribute the rest so the sums have matching parity.

Time Complexity: O(n) per test case.
Space Complexity: O(1).

Note:
This is the solution for Codeforces problem "Array Coloring" (CF 1857A).


C++ Code:

#include <bits/stdc++.h>
using namespace std;

int main()
{
    int t;
    cin >> t;

    while (t--)
    {
        int n;
        cin >> n;

        int sum = 0;

        for (int i = 0; i < n; i++)
        {
            int x;
            cin >> x;
            sum += x;
        }

        if (sum % 2 == 0)
            cout << "YES" << endl;
        else
            cout << "NO" << endl;
    }

    return 0;
}
